# F1Dle API

Here is my API for my F1Dle project. It contains data about Formula One drivers on the current grid.

Drivers which are not currently racing will be added later.

## Technology

- Laravel

## Data

My API provides informations about the current driver in Formula One such as :

- Name
- Surname
- Date of birth
- Nationality
- Current team
- Win counter
- Pole counter
- Podium counter
- Year of the first entry
- Number of the driver
- Fastest lap counter
- Number of points in career
- Entry counter
- Number of World Championship
